# Parametric trees from `samor_4077_133`

The source mesh is inside:

`Assets/Environment Aseets/02_第三方环境资源包/4077_卡通低面森林场景/Mountain Environment.fbx`

Five same-family variants were generated by adapting the recursive branch field
from Sky City's `SkyCityBotanyGeometry.cs` to the source tree's authored
low-poly mesh, UVs, and materials:

- `Spreading`: broad crown
- `Slender`: tall and narrow
- `WindSwept`: side-leaning crown
- `TwinFork`: split crown silhouette
- `LowCanopy`: compact low tree

Four larger fractal variants repeat the source tree as a smaller child motif at
recursive branch nodes:

- `FractalTowering`: tall three-way fractal crown
- `FractalBroad`: broad four-way crown
- `FractalAncient`: three-generation recursive crown
- `FractalSpire`: very tall three-generation spire

Run `Tools/build_samor_tree_family.py` in Blender to regenerate the FBX files
and `Previews/samor_tree_family.png`. Run `Tools/build_fractal_giants.py` for the
larger recursive variants and `Previews/samor_fractal_giants.png`.

The scene uses the standalone Unity mesh assets in `Meshes`; those were baked
with the current Unity version so they remain valid without requiring Unity
Additive or Asset Bundle builds.

`Monekey Mountain.unity` contains the five original variants and four
`samor_Tree_Fractal*` instances.
The pre-change scene is:

`Assets/Scenes/Monekey Mountain.backup-2026-11-02-pre-parametric-trees.unity`
