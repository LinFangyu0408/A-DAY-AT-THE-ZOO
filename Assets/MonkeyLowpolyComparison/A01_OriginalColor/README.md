# 棕色 01 原色 lowpoly 样稿

将 `MonkeyNPC_01_Lowpoly_OriginalColor.prefab` 拖入场景使用。此样稿引用 A_Restored 的网格、骨架、UV、蒙皮和挥手控制器；仅覆盖身体与五官材质。它尚不是完全独立的完整 NPC 资源包。

身体贴图是原版 `T_Chibi_Monkey_01.png` 的逐字节副本，未经重新配色、量化、提亮或去毛流处理。`Body_Original01.mat` 复制原 01 号的 Toon 着色器及全部保存参数，仅将身体贴图引用改为本目录副本。五官使用已验证的透明裁切材质，保留 alpha 通道。

`HighlandLake_01_ColorTest.unity` 是原场景的测试副本。验证在同一位置、同一相机、同一挥手姿态和同一场景光照下切换原网格与新版网格完成；原网格的五官材质统一为相同裁切材质，以便对比身体颜色。为隔离已打开的原场景，测试副本使用第 31 层，并同步调整测试灯光、相机和后处理体积的层掩码，未调整光照强度或调色参数。

对比图保存在 `work/monkey_lowpoly_sample/original_color/`：
- `01_Original_HighlandLake.png`：原版网格与原身体材质。
- `02_Lowpoly_OriginalColor_HighlandLake.png`：A 版网格与恢复后的原身体材质。

检查通过：原贴图与副本字节一致；身体所有保存参数一致（贴图资源引用除外）；A 版 Mesh 资源未变；91 根骨骼保留；0、0.33、0.66 秒挥手采样网格坐标有效；五官无黑底。原场景、原材质、原贴图及旧 A 版资源的文件哈希保持不变。

低多边形法线会让局部明暗与平滑原网格不同，这是切面效果，不是再次重新配色。本轮未验证完整九动作或迁移独立运行脚本；原场景未被此样稿替换。
