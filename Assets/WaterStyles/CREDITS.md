# Visual References

The shader in this folder is an original Built-in Render Pipeline
implementation. The six presets were prepared from these public references:

- `danielshervheim/unity-stylized-water` (BSD-3-Clause):
  https://github.com/danielshervheim/unity-stylized-water
- `IronWarrior/ToonWaterShader` (Unlicense):
  https://github.com/IronWarrior/ToonWaterShader
- `JiongXiaGu/LowpolyOcean` (MIT):
  https://github.com/JiongXiaGu/LowpolyOcean
- `MatrixRex/Uber-Stylized-Water` (MIT, URP only):
  https://github.com/MatrixRex/Uber-Stylized-Water
- `danielzeller/Lowpoly-Water-Unity` (MIT):
  https://github.com/danielzeller/Lowpoly-Water-Unity

The MatrixRex look is a Built-in Render Pipeline visual reconstruction rather
than the original URP shader, so its URP planar reflection and URP renderer
features are not imported.
