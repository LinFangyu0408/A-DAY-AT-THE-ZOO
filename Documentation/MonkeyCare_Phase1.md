# HighlandLake 猴子照顾与计分 v1.0

规则依据：用户提供的《猴子饲养VR游戏_计分文档_v1.0.docx》。目标场景：`Assets/Environment Aseets/01_HighlandLake_可玩场景/Scenes/HighlandLake_Backup_2026-11-03.unity`。

## 本版规则

- 总回合240秒：0–10秒熟悉手柄；有效任务截止230秒，最后10秒展示结算。READY GO为前3秒，期间SCORE、香蕉数量和倒计时隐藏，消失后一起显示；重开同样处理。时间从游戏相机就绪起计。
- 3只NPC各6项交替任务，每只喂食3次、挠痒3次，共18项。未出现的计划任务也计入未完成。
- 猴子1 `Monkey_Wave_01 (1)` 于15秒饥饿；猴子2 `02奶咖色猴子Wave` 于25秒发痒；猴子3 `Monkey_Wave_01` 于35秒饥饿。
- 成功完成后等待18秒；补救成功后等待22秒。第3项最早85秒，第5项最早155秒。等待从照顾成功时刻开始，包含成功动画时间。
- 每项期限30秒，最后10秒预警。恰好30秒完成仍为正常；超过期限只升级一次。正常喂食8秒、挠痒3次；补救总计10秒、4次，保留已有进度。补救完成后下一项恢复正常。
- 香蕉初始12根，仅喂食成功消耗1根；掉落可捡回，水下/离开区域则返回补给点。最多9项喂食，全部完成仍余3根。
- 初始48分，最终分数为 `48 + 52 × 已完成任务数 / 18`。不另外扣超时分。0项为零星，1–12项一星，13–17项两星，18项100分三星。
- 结算统计：Feedings Completed=成功喂食次数/9；Resolved Status=完成挠痒任务数/9的百分比（1位小数）；Tasks Completed=完成总数/18；Total Score保留2位小数。Next Star显示距离下一星的分数差，三星显示MAX。
- 230秒先处理截止时刻的有效完成再冻结；240秒开放Continue与Restart。Continue关闭结算并继续观察场景；Restart重置本局、库存和任务。

## 手柄和交互

右手Trigger选择、Grip抓取并保持；松开Grip放下。持物时松开Trigger不会丢物，直线射线仍显示。

- 喂食：香蕉持续接触猴子，或手持香蕉用直线射线瞄准饥饿猴子，累计有效时间。两种输入共用一个入口，同帧不重复累计。中断时暂停进度并回Hungry，继续后播放Eating。每项首次开始显示2.5秒SmokeExplosionWhite。成功消耗一根，Victory默认完整播放3次，随后Wave。
- 挠痒：手持痒痒挠接触猴子，沿跟踪空间向下移动8厘米计一次；向上抬回6厘米才能计下一次。静止、抖动、上抬、空挥不计。接触中断取消未完成动作，保留已完成次数。成功消耗工具，Cute1默认完整播放2次，随后Wave。
- 两种满意度条正常3段、补救4段，随Inspector次数配置变化。挠痒每次填满一段并短暂平滑；喂食按累计有效时间的平方填充。满条保持到成功反馈结束。耐心按`1−时间比例²`下降。
- sad在头部右侧、happy在左侧，朝向玩家；进度条保留在猴子头顶。
- 两种需求均显示传送点。瞄准后重新按Trigger确认；持物也可传送。空手指向地面时Trigger+Grip显示抛物线，松开按键确认有效落点。交互优先于移动。
- READY GO结束后SCORE显示、木箱上方香蕉数量显示，两种补给物高亮。拿起后显示上下晃动虚影与低强度右手震动；照顾期间暂停。放下、失焦、消耗或退出运行时清理。虚影无碰撞和射线响应。
- 成功消耗后2秒原位补给。每件物品同一时刻只服务一只猴子。

桌面预览以鼠标左/右键模拟Trigger/Grip、沿相机前方射线；桌面无法替代真实手柄运动和震动验收。

## Inspector 使用

选中NPC的 **Monkey Care Npc** 组件，可展开中文分组：

- **需求时间**：首次类型/延迟、后续等待、补救额外等待、期限。
- **喂食与挠痒**：正常/补救需求，以及下挠、抬回距离。
- **动画选择与播放**：各阶段动作类型或兼容Humanoid Clip、速度、结束方式。固定时长按游戏秒数；重复次数按片段完整播放次数。需求动画提前结束只停末帧，不跳过任务要求。成功动画的“跟随状态”按一次播放收尾；建议使用重复次数或固定时长。
- **特效**：Prefab、挂点、位置/旋转/缩放、颜色/渐变、持续时间。0秒表示跟随所属状态；Prefab自身是否循环仍由素材决定。运行时修改实例，不改共享材质。
- **UI和表情**：图片引用、头顶偏移、表情偏移、尺寸、分段间距。

**Monkey Care - 核心交互** 提供开场图、开场显示时间、射线、震动与回合UI图片引用。Round Artwork中的香蕉数量挂点绑定`Wooden crate_Lowpoly_Textured (1)`，可调整位置偏移和面板宽度；面板保持在木箱上方并朝向玩家。香蕉(9)与痒痒挠(10)上配置补给、抓握偏移、高亮及虚影。修改玩法默认参数后先试玩；播放中调试值退出后不会自动保存。

本版18项任务、230/240秒截止、85/155秒压力门槛和计分公式集中于 `CareRound.cs`，保持与文档一致。首次需求类型可在Inspector修改，后续仍交替、每类各3项；首次延迟最早为10秒，保留熟悉手柄时间。默认顺序遵循文档。

## 素材和场景

保留原环境与角色，使用现有香蕉(9)和痒痒挠(10)，未添加(11)。动画使用场景专用控制器，旧动作枚举值保持兼容。补齐已有素材包的CardglowType01及依赖；表情使用sad/happy切图。开场已取消MetalExplosionBig，改为金色放射光、飘带、四颗星和轻微弹出动画，3秒后一起消失。

结算由现有Results Screen、star、continue、restart拼接，场景作为后景，没有加入参考图底图。原面板烘焙的两项旧文字由UI层覆盖并显示文档新字段；原PNG保留。

菜单 **Tools → 猴子照顾 → 配置当前HighlandLake场景** 重绑引用并保存场景，执行前自动另存编辑器当前状态。重复执行不会重复创建组件/传送点，但会重绑默认素材和物品握持参数；手工调整这些参数后请先保存备份。

菜单 **Tools → 猴子照顾 → 运行逻辑自检** 执行边界与排程断言。编辑器的文件请求机制用于本次自动配置/测试，无请求文件时不执行任务。
